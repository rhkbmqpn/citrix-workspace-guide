## Key Features

Citrix Workspace app for Windows is the standard client for reaching virtualized Windows and Linux apps hosted in Citrix environments. Instead of installing every business app locally, users authenticate to a store URL and launch what IT assigns — with HDX session technology handling display, keyboard/mouse, clipboard, and multimedia redirection according to policy. The refreshed cloud UI reduces clutter with Home favorites, an Apps catalog, and a Desktops view, while Activity Manager keeps running sessions under control. For Windows 10/11 users this guide focuses on a clean download path, first connection, and what the main screens look like before you contact your administrator for store details.

- **Virtual apps & desktops access:** Launch Citrix-published apps and desktops from a single Windows client after store authentication.
- **Modern Workspace UI:** Home, Apps, and Desktops tabs with favorites, recent items, search, and category filters (cloud stores).
- **Session controls:** Activity manager helps disconnect or log off apps and power-control desktop sessions when policy allows.
- **Multiple entry points:** Open resources from the Workspace UI, desktop/Start menu shortcuts, or supported browsers.
- **Broad Windows coverage:** Designed for Windows 10 / Windows 11 endpoints used in home-office and enterprise fleets.
- **Admin-ready client:** Works with StoreFront and Citrix Cloud Workspace stores configured by your IT team.
